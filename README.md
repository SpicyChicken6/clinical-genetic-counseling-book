主要内容包括：

- **变异命名与分类：** HGVS 命名、PVS1、PS1/PM5、PS2/PM6、PS3/BS3、PS4、PM3/BP2、PP1/BS4、PP3/BP4、PM2/BS1/BA1 等证据的应用。
